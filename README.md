# sdd-kit-demo

Repositório de demonstração do [sdd-kit](https://github.com/fabiodrneles/sdd-kit): um projeto real, o `linkcheck` (CLI em Go que encontra links quebrados em arquivos Markdown), construído do zero com Spec Driven Development.

Acompanhe o processo pelos artefatos, na ordem:

1. [`specs/ANALYSIS.md`](specs/ANALYSIS.md): decisões iniciais do dono (D1–D4).
2. [`specs/`](specs/README.md): constituição, specs com critérios de aceite e [ROADMAP](specs/ROADMAP.md).
3. [Issues](https://github.com/fabiodrneles/sdd-kit-demo/issues): um épico por fase, um ticket por tarefa.
4. [Pull requests](https://github.com/fabiodrneles/sdd-kit-demo/pulls?q=is%3Apr): um por ticket, com CI verde e cada critério de aceite citado por um teste.

O uso do `linkcheck` entra aqui na Fase 1.
